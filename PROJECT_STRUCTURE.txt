KEY FEATURES:
=============
✅ Student Management (CRUD)
✅ Hall Management (CRUD)
✅ Exam Scheduling
✅ Intelligent Seating Allocation (No adjacent same-dept students)
✅ Fair Invigilator Assignment (Workload balancing)
✅ Dashboard with Statistics
✅ Visual Seating Plan Grid

TECHNOLOGY STACK:
=================
Backend:  Spring Boot 3 + Java 17 + JPA/Hibernate + MySQL
Frontend: React 18 + Vite + Tailwind CSS + Axios
Database: MySQL 8.x (11 tables, fully normalized)

ALGORITHMS:
===========
1. Seating Allocation: O(n × h) constraint-based greedy
2. Invigilator Assignment: O(h × i) weighted round-robin
